## 📁 Contents

### 🔍 [EDR Lab – TryHackMe](./EDR-lab.md)
**Platform:** TryHackMe  
**Topics:** Endpoint Detection & Response (EDR), Alert Triage, Threat Investigation  

Hands-on lab using a simulated EDR dashboard to investigate endpoint alerts across a network. Tasks included identifying malicious file paths from command-line activity and triaging multi-device alerts. Key takeaway: understanding the difference between SIEM and EDR tooling and why both are necessary in a SOC environment.
